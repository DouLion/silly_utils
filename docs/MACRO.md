| 平台       | 推荐宏               |
|------------|----------------------|
| Windows    | `_WIN32`             |
| Linux      | `__linux__`          |
| macOS      | `__APPLE__` + `__MACH__` |
| Unix-like  | `__unix__`           |
| GCC        | `__GNUC__`           |
| Clang      | `__clang__`          |
| MSVC       | `_MSC_VER`           |
